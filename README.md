# FSD System Guidelines

Welcome to the Full Self-Driving (FSD) system!  
Your vehicle can drive itself in many situations, but **you must always supervise the system** and be ready to take control at any time.

---

## ⚠️ Safety
1. **Always pay attention.** FSD can control steering, acceleration, and braking, but you are responsible for the vehicle at all times.   
3. **Follow traffic laws.** The system is designed to assist you, not replace legal driving responsibilities.  
4. **Do not misuse the system.** Reckless driving, unsafe behavior, or bypassing FSD safety features is strictly prohibited.  
5. **Report issues responsibly.** If something behaves unexpectedly, notify the FSD team—do not try unsafe workarounds.  

---

## 📌 Strike System
FSD uses a **5-strike policy** to enforce proper usage:

| Strike | Action |
|--------|-------|
| **1**  | Warning; reminder to follow guidelines. |
| **2**  | Certain FSD features temporarily restricted. |
| **3**  | Access to advanced features disabled for 7 days. |
| **4**  | Account flagged; mandatory review before reinstatement. |
| **5**  | Permanent revocation of FSD access; user banned from system. |

> Strikes are cumulative and can only be removed with approval from the FSD team after corrective action.

---

## 🧠 Best Practices
- Always supervise the vehicle, even in automatic mode.  
- Avoid relying on FSD in poor weather or low-visibility conditions.  
- Keep the system updated to the latest version for safety and performance.  
- Never share access credentials or let unauthorized users operate the vehicle.
